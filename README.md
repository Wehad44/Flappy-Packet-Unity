# Flappy Packet 

A 2D arcade-style game developed using Unity and C#. Inspired by the classic Flappy Bird gameplay, the project includes multiple levels, character selection, collectible coins, scoring mechanics, sound effects, and unlockable gameplay progression.

##  Features

- Classic side-scrolling arcade gameplay
- Multiple playable levels
- Character selection system
- Coin collection and coin counter
- Score tracking
- Pipe spawning and movement mechanics
- Unlockable levels
- Main menu and level selection menu
- Audio and sound effects
- Custom game graphics and animations
- Finish screen and game progression

##  Technologies Used

- Unity 2021.3.45f1
- C#
- Unity 2D Physics
- Unity Animator
- Unity Audio System
- Unity UI
- Prefabs and Scenes

##  Project Structure

```text
Assets/
├── Scripts/             # Gameplay and game management scripts
├── Scenes/              # Game scenes and levels
├── coin/                # Coin-related scripts and assets
├── CPic/                # Game graphics and UI assets
├── Sounds/              # Audio files and sound effects
└── TextMesh Pro/        # Text rendering assets

Packages/                # Unity package dependencies
ProjectSettings/         # Unity project configuration
```

##  How to Run

1. Install Unity Hub.
2. Install Unity version `2021.3.45f1`.
3. Clone this repository:

```bash
git clone https://github.com/Wehad44/Flappy-Packet-Unity.git
```

4. Open Unity Hub.
5. Click **Add** and select the cloned project folder.
6. Open the project using Unity `2021.3.45f1`.
7. Open the main menu scene and press **Play**.

##  Gameplay

The objective is to navigate the character through obstacles, collect coins, achieve a high score, and progress through the available levels.
